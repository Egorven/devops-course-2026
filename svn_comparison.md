1. Почему в Git ветвление "дешёвое", а в SVN — "дорогое"?
В Git ветвление является легковесным, так как ветка представляет собой указатель размером 41 байт на коммит, в то время как в SVN ветвление реализовано как физическое копирование директории на сервере.

2. Можно ли в SVN сделать коммит без интернета? Почему?
Сделать локальный коммит без подключения к интернету в SVN невозможно, поскольку это централизованная система, требующая связи с сервером для записи изменений.

3. В каких сценариях SVN до сих пор может быть предпочтительнее Git?
SVN может превосходить Git в сценариях с огромными монорепозиториями, необходимостью частичного скачивания каталогов (Sparse Checkout) и жестким разделением прав доступа на уровне подпапок.
